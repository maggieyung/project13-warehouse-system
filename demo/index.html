Warehouse Order Fulfillment

Type commands into the console the same way you would in ./build/warehouse. Orders check and reserve stock up front. If any line is short, the whole order is rejected and nothing changes. The stock and order panels update as you go.

What happens when you place an order

  1. Parse the commandrunOrderCommand() splits the line and checks each SKU:qty pair. Quantities must be whole numbers above 0.
  2. Combine duplicate linesSKU-100:6 SKU-100:6 becomes one request for 12 before stock is checked.
  3. Check every lineOrderBook::createOrder() rejects unknown SKUs first, then any line that asks for more than is available.
  4. Reserve all or nothingStock is taken only when every line fits. A rejected order leaves stock alone and doesn't use up an order id.
  5. Fulfill laterfulfill <orderId> moves a pending order to fulfilled. Stock was already reserved, so it doesn't change.

Commands

  • order <customerId> <SKU>:<qty> [...] creates an order.
  • fulfill <orderId> marks a pending order fulfilled.
  • quit ends the session. Use Reset session to start over.
  • Press ↑ and ↓ in the console to go through earlier commands.
